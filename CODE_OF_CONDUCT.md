# Code of Conduct

IconNook follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming and respectful, give and accept constructive feedback gracefully, and focus on what's best for the community. Harassment, insults, discriminatory language, and publishing others' private information are not tolerated.

## Reporting

Report unacceptable behavior privately to the maintainer via GitHub ([@hareeshagunasekara](https://github.com/hareeshagunasekara)). A dedicated contact address will be added once iconnook.com email is set up. All reports are reviewed promptly and kept confidential.

Maintainers may remove, edit, or reject contributions, and temporarily or permanently ban contributors, for behavior they deem inappropriate, following the enforcement guidelines of the Contributor Covenant.
