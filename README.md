# IconNook

**Free, open-source SVG icons — every one clearly licensed.**
[iconnook.com](https://iconnook.com) · no payments, no sign-up walls, no attribution surprises.

> **Status:** early development. Follow progress in [docs/PLAN.md](docs/PLAN.md).

## What it will be

- Hundreds of thousands of open-source icons from 150+ sets (Material Symbols, Fluent, Phosphor, Tabler, Lucide and more)
- Fast search with filters by style, set, color and license
- Customize color, size and stroke; copy as SVG, JSX, Vue, Svelte, data URI or CSS; download SVG or PNG
- A clear license on every icon — and a ready-made credit line when one is required
- Built to be fast and accessible to everyone (WCAG 2.2 AA)

## Tech

TypeScript · Astro + Preact + Tailwind · Hono · PostgreSQL + Drizzle · Meilisearch · Valkey · Docker · k3s · Cloudflare
