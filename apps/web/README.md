# @iconnook/web

The iconnook.com website — Astro with Preact islands and Tailwind CSS v4. Currently a placeholder home page with the base accessible layout (skip link, focus styles, reduced motion, light/dark tokens). Full UI arrives in Phase 5 (see [docs/PLAN.md](../../docs/PLAN.md)).

```sh
pnpm --filter @iconnook/web dev        # http://localhost:4321
pnpm --filter @iconnook/web build
pnpm --filter @iconnook/web typecheck  # astro check
```
